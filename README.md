# Tutorial 5A - Borrow Book System

Java GUI application using Java Swing.

## Project Description

This project is a Borrow Book System that allows users to:

1. Add Student Information
2. Add Book Information
3. Borrow Books

## Java Files

- MainMenu.java
- Student.java
- Book.java
- BorrowData.java
- AddStudentGUI.java
- AddBookGUI.java
- BorrowBookGUI.java

## Programming Language
Java
